Nunito (Vernon Adams, Cyreal, Jacques Le Bailly) and Caveat (Impallari Type), from Google Fonts.
Nunito is the latin subset. Caveat is cut further to ASCII and typographic punctuation, since it only
sets the interface's own labels (filters, legends); a character outside that falls back to the next font.
